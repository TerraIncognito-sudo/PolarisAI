Schema requests

  • Hedging: Add a hedge_currency column (CAD, USD or none). cad_hedged is currently 1 for any hedged fund, so BNDW and BNDX (hedged to US dollars) look CAD-hedged.
  • Broad funds: Add a broad_market flag (1 = whole-market index fund). The site currently guesses from fund names to keep single-country, factor and target-maturity funds out of the core picks.
  • Themes: Add theme tags (or an app_theme table) for the eight step 4 themes: inflation-protected bonds, real estate, gold, infrastructure, Asia-Pacific, energy, technology, clean energy. Gold and Asia-Pacific have no tag today.
  • Step 4 lists: Decide whether swap and second-fund lists should be generated from the data (next-lowest fees, correlation under 0.95) or stored as a table (app_swap: category, ticker, rank). Either way, every ticker used must be eligible.
  • Assumptions: Optional: move the expected-return assumptions per category into a table (capital_market_assumptions) so they are versioned with the data.
  • Active funds: Optional: add an is_active flag so the site can say whether a fund tracks an index or is actively managed.
